# 表格视觉与交互验收

本轮范围是24张业务表的排序、分页、筛选、完整导出/提交语义，以及下列固定视觉场景；不把截图数量等同于业务正确性，也不承诺穷尽所有数据和设备。

## 场景与尺寸

所有场景覆盖亮/暗两主题、320×900 / 768×900 / 1440×900。主要页面包括终端、资源、机柜、配置、设备、模板、位置、提醒、审计、通知、备件、盘点、审批、账户。补充场景包括设备类型、库存统计、库存流水、备件规格、最低库存、选中盘点任务后的明细/发现记录、配置弹窗的关联部件；PDU详情、批量导入和机柜图校验预览单独覆盖。

自动检查页面宽度、窄屏固定列释放、真实分页/排序/编辑对象和权限；截图用于人工核查布局、颜色、遮挡与文字。对应脚本为frontend/e2e/table-workflows.spec.ts。截图和浏览器认证轨迹仅保存在103私有证据区，不进入Git。

## 视觉检查发现并修复

- 手机宽度下固定操作列覆盖完整数据区。修复为600px以下释放固定列，允许表格内部横向滚动；桌面保留固定操作列。断言使用Element真实的el-table-fixed-column类，并确认终端首列实际可见。
- 大屏的1100px最小内容宽度撑大整个文档，使小屏弹窗不再以真实视口布局。改为大屏内部横向滚动，保留机柜画布尺寸与桌面布局。
- 批量导入统计四列在手机上挤压文字。改为两列；弹窗限制高度并滚动内容，保留底部关闭/提交入口。
- PDU表随全部当前页插座无限增高。限制表格滚动区高度，保留分页和分组身份；PDU面板及机柜详情标题使用主题文字/背景变量，底部按钮换行。
- 机柜图校验统计卡片使用主题变量，弹窗内容可滚动，窄屏提示与按钮换行。
- 资源页在小屏改为纵向排列、取消桌面最小高度，设备统计卡片改为两列；设置抽屉和弹窗表格使用同一主题适配，避免暗色悬停变成白底。

## 数据与业务验收

组件回归使用真实Element控件：资源/机柜/配置/PDU各61行，关联部件61行；批量导入241行、失败项单独重试；机柜图61项决策，隐藏未决项仍阻止提交。PDU快速切柜的延迟响应不能覆盖新柜数据，旧编辑弹窗关闭。

真实隔离后端浏览器覆盖61插座分页并打开第二页插座21的编辑表单；241行Excel预览；从当前机房真实导出机柜图再回读校验。普通user角色可以查看配置和导出，隐藏配置写操作，管理API返回403且管理页面拒绝进入；这不改变原有普通用户在机柜等核心模块的权限设计。

PDU连接/断连、数量库存调拨、盘点差异关闭、审批执行四类真实HTTP闭环见scripts/business_workflows.py。连接接口仍依赖事务内状态/柜位检查；此轮没有声称新增了连接请求version的后端校验。
