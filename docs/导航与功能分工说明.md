# 导航与功能分工（preview.15）

| 导航分组 | 入口 | 职责 |
|---|---|---|
| 工作台 | 运行概览、提醒中心、审批中心 | 运行汇总、风险处理与审批待办 |
| 资产管理 | 终端台账、机房备件、配置与保修中心、扫码盘点、扫码查询 | 日常资产运营与共用配置保修维护 |
| 机房资源 | 区域与机房、机柜管理、机房设备台账、机房大屏 | 机房资源、设备上架/迁移/下架与 U 位 |
| 基础资料 | 区域与资产位置、机柜模板 | 公共位置引用与机柜标准模板 |
| 系统管理 | 资产操作记录、数据导出与备份、通知发送记录、告警通知、审批规则、扫码访问设置、账号与认证 | 记录追踪、业务资料、管理员策略与配置；按原角色显示各入口 |

## 去重规则

- 终端与机房设备各自从台账登记；配置与保修中心不再提供两套台账跳转按钮，也不重复创建资产。
- 配置与保修中心移除位置、操作记录、导出备份、提醒页签；四项功能改为独立路由并复用原接口。
- 业务页的筛选/勾选导出继续保留；“数据导出与备份”负责完整业务资料和系统备份指引，职责不同。
- 区域与机房管理物理机房资源；资产位置管理办公区、库房等通用业务位置，机房位置通过关联引用原有机房，不复制机柜数据。
- 业务数据、设备 ID、二维码、位置引用和历史记录保持原样。此前下架审批开关保持；本版新增双渠道审批及备件备注相关字段，详见《双渠道审批与备件布局说明》。

## 兼容与权限

旧 `/asset-operations?tab=sites/reminders/audit/backup` 分别跳转到 `/asset-locations`、`/asset-reminders`、`/asset-audit`、`/asset-data`；保留其他查询参数和锚点。旧 `/pc-assets` 与 `/terminal-assets` 都可使用，导航统一显示终端台账。

系统管理员、资产管理员和资产审计员可访问公共业务页面；位置和提醒的修改仍限管理员/资产管理员，审计员只读及导出。审批中心、通知发送记录及系统配置功能限系统管理员；系统管理分组中的资产操作记录和业务导出保留原资产角色权限。后端继续执行原权限校验。

## 部署

离线包需要已安装 Docker 和 Docker Compose 的 Linux amd64 服务器，全新安装解压后执行 `bash install.sh`，默认端口 15173。升级必须复制原有效安装目录 `.env` 到新目录并保持 600 权限，保留原数据库密码和 JWT_SECRET；不要删除数据库卷。完整系统备份需使用包内受限脚本，业务 JSON 不能替代数据库备份。

本版未重打 Android APK。未完成真实 Docker/PostgreSQL 升级联调或浏览器视觉验收。
