# 设备台账导出修复（preview.4）

- 修复列表使用上次查询条件、导出使用未提交条件导致空表的问题。类型与生命周期切换立即查询；关键词在查询或打开导出时应用。分页使用已应用的查询条件。
- 表格提供逐台勾选、当前页全选、跨页保留和清空勾选。变更查询条件后清空勾选，避免混入其他查询结果。
- 导出对话框可选择当前筛选结果（包含所有分页）或仅勾选设备；分类复选框支持同时选择 PC、服务器、网络设备等多个分类。分类在所选范围内进一步筛选。
- 勾选导出会重新读取设备详情。所有分页读取成功且无重复、缺失后才生成 Excel；无数据或读取失败时不下载空表、半份文件。
- 保留设备编码、SN、规格、保修日期、管理 IP、机房机柜及 U 位等现有字段；不新增资金类字段。

## 升级

先按原备份说明备份数据，将原正常运行目录的 .env 复制到新包目录，再执行 bash install.sh。保留原数据库密码和 JWT_SECRET；不删除数据卷。

## 验证及边界

专项测试覆盖 205 台设备跨页获取、勾选读取、分类过滤、待提交关键词、空结果阻止下载、分页失败和 Excel 字节写出后重新读取 SN/规格/位置。完整前端类型检查、测试和生产构建均需通过后打包。
本机没有运行 Docker/PostgreSQL，因此镜像启动与真实旧库升级仍需在测试服务器验收；安装流程采用模拟 Docker 检查，镜像与安装包按文件清单和镜像层摘要回读校验。
