# IT 基础设施管理平台 · 0.2.0-preview.16

发布日期：2026-10-21。

本次进一步简化机房备件：日常只保留库存明细、机房统计、库存流水，规格及最低库存迁入辅助设置。录入默认直接填八项，支持四种初始状态；每条记录提供完整详情和专属流水，新增状态前后值及位置变化展示。保留库存及历史引用保护。详见《备件工作台使用说明》。

此前支持审批邮件和企业微信同时通知，独立开关/去重/重试及测试；新审批邮件发送记录包含收件人和 Message-ID。现有机房备件改为八字段主表，增加备注和区域/类型筛选；入库一次完成建档和数量登记，直接调拨、收货、流水入口替代笼统的办理，保留原库存追踪与历史；导航重新归为工作台、资产管理、机房资源、基础资料、系统管理五组。详见《双渠道审批与备件布局说明》。

此前分离审批待办、审批规则、通知发送记录与账号认证；新增默认开启的下架审批，修复直接释放 U 位绕过审批的问题。设备台账、大屏正确提示待审批状态，机柜图导入不能绕过开启的下架审批。批准时重验设备版本和原位置并在事务中执行下架，旧审批邮件链接继续兼容。详见《审批与通知布局及下架审批说明》。

此前整理导航与功能分工：配置与保修中心只保留共用档案的配置/保修维护，移除重复台账按钮；终端台账归资产运营，机房设备台账归基础设施；区域与资产位置归基础资料；资产操作记录和数据导出与备份归数据与审计；提醒中心独立到工作台。旧中心页签链接自动跳转，保留原 CRUD、权限、业务导出与备份脚本，不迁移或删除业务数据。详见《导航与功能分工说明》。

此前将“资产与保修”明确为共用档案的“配置与保修中心”，取消重复登记入口，终端与机房设备分别从自己的台账登记。终端新增表单、使用履历和导出使用在库/使用中/维修中/已报废，不再混用机柜生命周期；增加初始状态原子登记、维修/维修完成/报废履历，阻止使用中设备直接报废和绕过流程改状态。详见《台账分工与终端状态说明》。

此前将 PC 入口统一为“终端管理”，内置显示器、主机、打印机、笔记本、鼠标、键盘、其他终端七种类型，支持类型筛选和导出。旧 PC 类型保留 ID 并仅对原系统默认名称改为“终端（待细分）”，不猜测旧设备具体类型。原领用、归还、交接、二维码及历史继续使用。详见《终端分类说明》。

此前分开机房设备与 PC 终端入口：机房设备继续维护 U 位，PC 终端由管理员确认领用、归还和换人交接。自动更新使用人/部门/位置，正常归还转闲置，故障归还转维修；新增不可直接修改的交接记录、完整记录导出和业务备份。复用原设备档案和二维码。详见《PC领用归还说明》。

此前新增审批邮件通知：系统管理 → 审批设置中可启用通知、填写管理员收件邮箱和系统访问地址，复用已有 SMTP。每分钟检查待审批申请；成功后不常规重复发送，失败记录并在 15 分钟后重试。邮件链接进入待审批列表，必须登录管理员账号后处理。详见《审批邮件通知说明》。

此前集中修复扫码及二维码链路：系统码保留对象类型，规范 UUID 和重复参数；查询及任务请求防止旧响应覆盖；摄像头在取消、失败、确认、后台和离开页面时释放；标签窗口在用户点击时同步预留，防止异步弹窗被拦截；二维码增加留白及生成分辨率，并展示 SN。另修复扫描路由切回空入口后旧结果未清空的问题。详见《扫码二维码排查与优化记录》。

此前整合新增/编辑设备的“二维码与标签”区域：系统二维码按统一地址自动生成，保存后可查看和打印；外部编码及原链接作为已有标签的绑定，扫码查询与盘点可识别。外部链接不替代系统链接，不自动访问外部网站。详见《二维码与外部标签说明》。

此前新增“系统设置 → 扫码访问设置”，支持配置设备/备件标签及手机扫码入口的统一 HTTP/HTTPS IP 或域名，配置共享保存于数据库，并有管理员权限、版本冲突及操作审计保护。保留旧二维码的页面内识别能力。配置不会自动修改监听、DNS、证书或公网入口。详见《扫码访问配置说明》。

此前已统一软件名称为“IT 基础设施管理平台”，更新登录页、导航栏、浏览器标题、二维码资产标签、Excel 导出作者和告警通知中的产品名称。保留此前设备分类/勾选导出、位置与备件维护、邮箱/企微告警功能。

## 升级与安装

完整离线包文件名：cabinet-it-assets-offline-0.2.0-preview.12-linux-amd64.tar.gz。
需要服务器已安装 Docker Engine 和 Compose v2，操作系统为 Linux x86_64。

升级前备份数据，将上个正常运行目录的 .env 复制到新目录；原数据库密码、JWT_SECRET、项目名和数据卷保持不变。先查找实际旧目录中的 .env（只列路径，不显示密码），再将下面 OLD_DIR 改为原正常运行的真实目录，不能填写新目录自身：

```bash
find /home/inno -maxdepth 4 -type f -name .env -path "*/cabinet-it-assets-*/*" -print
```

```bash
tar -xzf cabinet-it-assets-offline-0.2.0-preview.12-linux-amd64.tar.gz
cd cabinet-it-assets-offline-0.2.0-preview.12-linux-amd64
OLD_DIR=/home/inno/原正常运行版本目录
if test -s "$OLD_DIR/.env"; then
  install -m 600 "$OLD_DIR/.env" .env && bash install.sh
else
  echo "未找到原配置，请选择曾正常启动的旧安装目录，不要生成新密码。"
fi
```

全新安装直接进入新目录执行 `bash install.sh`。默认访问 http://服务器IP:15173。
容器项目名仍为 cabinet-it-assets，原数据卷继续使用，不因产品显示名调整而迁移或重建数据。
