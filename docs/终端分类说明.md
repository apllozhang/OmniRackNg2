# 终端分类与领用管理

版本：0.2.0-preview.11。

原“PC 终端管理”统一改名为“终端管理”，与机房设备分开。终端包含以下设备类型：

| 类型 | 登记内容示例 |
| --- | --- |
| 显示器 | 品牌、型号、尺寸/分辨率、SN 或资产编号 |
| 主机 | 品牌、型号、CPU、内存、硬盘、SN |
| 打印机 | 品牌、型号、SN、网络地址、保管责任人 |
| 笔记本 | 品牌、型号、CPU、内存、硬盘、SN |
| 鼠标 | 品牌、型号、资产编号，可选 SN |
| 键盘 | 品牌、型号、资产编号，可选 SN |
| 其他终端 | 按具体设备记录型号、规格和保管责任人 |

在“终端管理 → 登记 / 编辑终端档案”选择具体设备类型；新登记不自动猜测类型。原有配置字段继续复用，尺寸、分辨率等可填写在规格说明中。本次不新增资金字段。

终端列表支持按类型、使用状态、位置筛选，并可搜索使用人、部门、SN 或设备编码。导出包括具体“终端类型”；选中时导出勾选项，未选中时导出筛选结果。

鼠标、键盘按件管理，每件有独立设备编码和二维码。没有厂商 SN 时可以留空，通过设备编码/资产编号及二维码识别；没有增加数量库存或消耗品出入库机制。

所有终端沿用管理员确认领用、归还、换人交接流程，故障归还进入维修中。打印机等共享设备可登记实际保管责任人和所属部门。每次操作记录前后使用人/位置和管理员确认信息，历史支持完整导出，详见《终端领用归还说明》（文件名沿用 `PC领用归还说明.md`）。

## 旧数据兼容

- 原 PC 分类继续作为底层兼容编码，统一显示为“终端”，不重建档案、二维码或交接记录。
- 原默认设备类型 `PC / PC 终端` 仅名称更新为“终端（待细分）”，ID 保持不变，已有终端不会自动改成主机或笔记本。管理员核实后可在编辑档案时选择具体类型。
- 自定义的既有类型名称、分类和已停用/已删除状态不被初始化覆盖；新内置类型按唯一类型编码补齐。
- 新入口 `/terminal-assets` 与旧 `/pc-assets` 均可访问；旧客户端、业务导出字段和交接接口保持兼容。

升级使用原 `.env` 和数据卷；先备份，再运行新版离线安装脚本。本版针对 Web 管理端，Android APK 未重新打包。分类初始化、旧名称兼容和无 SN 外设领用使用模拟数据库/界面组件测试验证，真实数据库升级及页面视觉仍需测试环境验收。
